# 🔤 Quintos AI Typography System

Version: 1.0

---

# Purpose

The Quintos AI Typography System establishes a consistent hierarchy for text across all products, marketing pages, dashboards, documentation, and future AI applications.

Goals:

* Improve readability
* Maintain visual consistency
* Establish a premium brand identity
* Support responsive layouts
* Ensure accessibility

---

# Font Family

## Primary Font

**Inter**

Reasons:

* Excellent readability
* Optimized for UI
* Modern appearance
* Widely supported
* Great at small sizes

Fallback:

```text
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
"Segoe UI", Roboto, Helvetica, Arial, sans-serif
```

# Accessibility

* Minimum body size: 16px
* Maintain sufficient line height
* Avoid long lines (>75 characters)
* Preserve readable contrast ratios
* Do not use all-uppercase for long paragraphs

---

* Minimal font families
